Public Health Program Data Analysis & Reporting (Amref Case Study)
An end-to-end data processing, exploratory analysis, and automated reporting project designed to analyze community health program performance and key health indicators.

Project Overview
This project simulates a routine Monitoring & Evaluation (M&E) reporting pipeline for a community health intervention program. The goal is to ingest raw field survey data, clean and standardize records, calculate key performance indicators (KPIs), and generate actionable visual reports for stakeholders.

Key Objectives
Data Ingestion & Cleaning: Handle missing values, standardize region names, and correct data types across raw field datasets using Python (pandas).

Relational Querying: Write SQL queries to aggregate health metrics by county, program module, and demographic groups.

KPI Dashboarding: Build automated visual summaries tracking project output against target goals.

Reporting: Synthesize insights into an executive-ready summary report.

Tech Stack
Language: Python 3.10+

Libraries: Pandas, NumPy, Matplotlib, Seaborn

Database: SQLite / PostgreSQL (SQL queries included in scripts/queries.sql)

Environment: Jupyter Notebook / Google Colab
